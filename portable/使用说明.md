# OriDrug 0.7.1 个人工作台

工作台包含网页、数据库、任务队列，以及 RDKit、AutoDock Vina、OpenMM、PyMOL、R 和 ggplot2。第一次打开页面时点「注册」，然后建立自己的研究项目。

## Windows 本机使用

1. 在网站首页运行「环境检测」，根据结果开启虚拟化、配置 WSL 2 并安装 Docker Desktop。打开 Docker Desktop，等 Linux 引擎就绪。发行镜像适用于 x86-64 处理器。[Docker 官方安装页](https://docs.docker.com/desktop/setup/install/windows-install/) · [微软 WSL 安装说明](https://learn.microsoft.com/zh-cn/windows/wsl/install)
2. 解压 `OriDrug-Launcher-Windows.zip` 到准备长期使用的目录，例如数据盘的 `OriDrug` 文件夹。
3. 双击 `Start-OriDrug.cmd`。第一次启动会从项目的 GitHub Release 下载两个文件，校验后导入 Docker，并初始化数据库。准备完成后浏览器会打开 [个人工作台](http://127.0.0.1:8789/)。
4. 双击 `Stop-OriDrug.cmd` 可以暂停服务。再次使用时，回到同一目录双击启动。

下载文件、实例密钥保存在启动器旁的 `.oridrug` 文件夹。研究项目、账号和计算产物使用 Docker 数据卷。备份工作台时请同时保留两者。选择 Docker 数据的存储盘，可在 Docker Desktop 设置中的 **Resources → Advanced → Disk image location** 修改。

如果要在离线电脑上安装，请在可以联网的电脑打开[本版下载页](https://github.com/leisuper2006-collab/oridrug/releases/tag/v0.7.1)，下载启动包和两个 `linux-amd64.tar.gz` 文件。将两个镜像文件放进同一文件夹，在解压后的启动器目录运行以下命令。把引号中的内容换成镜像文件夹的路径。

```powershell
.\Start-OriDrug.cmd -ImageDirectory "镜像文件夹"
```

电脑里已有工作台占用 8789 端口时，可用以下命令在 8790 端口运行这份个人工作台。

```powershell
.\Start-OriDrug.cmd -Port 8790
```

## GitHub Codespaces

打开[运行个人云工作台](https://codespaces.new/leisuper2006-collab/oridrug?quickstart=1)，用自己的 GitHub 账号创建工作空间。首次启动会下载并校验同一版本的运行文件。在「端口」面板打开 **8789 · OriDrug 工作台**。工作空间的计算额度与存储按该账号的 Codespaces 方案计算。[GitHub 端口转发说明](https://docs.github.com/en/codespaces/developing-in-a-codespace/forwarding-ports-in-your-codespace)

在仓库根目录可以用 `bash portable/start.sh` 重新启动，使用 `bash portable/start.sh --stop` 暂停。本机 Linux x86-64 也可以使用这两条命令，需先准备 Docker Engine、Compose、Bash、curl、OpenSSL、util-linux 和 GNU coreutils。

## 随附软件与公开数据

- 结构和公开数据快照随科研镜像提供。RCSB 2HYY、1M17 和 AlphaFold P00533 的来源、许可和校验值见镜像内 `/app/data/references/README.md`。[RCSB 2HYY](https://www.rcsb.org/structure/2HYY) · [AlphaFold P00533](https://alphafold.ebi.ac.uk/entry/P00533)
- ADMET 数据来自 TDC。BRD4 的配套拓扑和坐标保留上游 BSD 3-Clause 许可，来源与版本分别保存在 `/app/data/admet/README.md` 和 `/app/data/brd4/README.md`。[TDC 数据集](https://doi.org/10.7910/DVN/21LKWG) · [BRD4 上游版本](https://github.com/MobleyLab/benchmarksets/tree/5233e0a1529b3c3ba9adf8c245de2b658e5fbf40)
- 科研运行环境以 Debian 和 Python 为基础，系统软件的版权文件位于镜像内 `/usr/share/doc`，Python 发行包的许可随相应包提供。Vina 使用 1.2.7，参考对接文件含上游许可。[Debian 源码](https://sources.debian.org/) · [AutoDock Vina 源码](https://github.com/ccsb-scripps/AutoDock-Vina/tree/v1.2.7) · [PyMOL Open Source](https://github.com/schrodinger/pymol-open-source)
- 数据库使用官方 PostgreSQL 17.12 Alpine 镜像。网页服务器使用 Caddy 2.11.9，Apache License 2.0。中文与西文字体的许可位于网页的 `/licenses/` 目录。[PostgreSQL](https://www.postgresql.org/) · [Caddy](https://github.com/caddyserver/caddy)
