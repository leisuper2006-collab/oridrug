# OriDrug 科研工作台

[打开网页并登录](https://leisuper2006-collab.github.io/oridrug/) · [下载 Windows 和 Android 应用](https://github.com/leisuper2006-collab/oridrug/releases/tag/v0.8.0)

从研究问题出发，将 18 个药物研发阶段的证据、数据、计算和实验记录放在同一项目里。首页收录 98 张工作台实拍及各阶段演示。蛋白质与伊马替尼的展示取自[人 ABL1 实验结构 PDB 2HYY](https://www.rcsb.org/structure/2HYY)。

## 第一次使用

选择注册，进入「我的项目」。可新建自己的课题，也可载入伊马替尼公开案例。网页和两款应用共用跨端研究账号。首次在新设备登录时联网，已有设备可离线使用。项目先在设备上加密，联网后同步。在「我的」可导出、恢复加密备份或导出项目报告。

进入具体阶段即可保存记录与附件，检索文献和试验，检查表格或比较分子性质。需要电脑计算时，手机可将任务转交电脑。Windows 应用会在对应的功能内检查科研环境、协助安装并展示任务回执。

## 完整科研环境

运行本机科研服务或 GitHub Codespaces 可使用 [0.7.1 完整科研运行工具](https://github.com/leisuper2006-collab/oridrug/releases/tag/v0.7.1)。该服务的本机账号和项目使用独立数据库，工作台端口为 8789。
