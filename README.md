# OriDrug 科研工作台

[打开 OriDrug 网站](https://leisuper2006-collab.github.io/oridrug/)

跟随伊马替尼案例，从疾病与研发目标、分子结构和计算研究，一直看到实验记录、临床前开发及上市后证据。网站收录 18 个研究阶段、98 张工作台实拍和逐阶段演示。

## 运行自己的工作台

在网站首页选择 **开始使用**。Windows 用户可以先运行 **检查我的电脑**，查看 Docker 和 WSL 的安装情况，再下载启动包。也可以在 GitHub Codespaces 中启动独立工作台并打开 8789 端口。每个工作台有自己的账户、项目和计算记录。

伊马替尼三维展示采用[人 ABL1 实验结构 PDB 2HYY](https://www.rcsb.org/structure/2HYY)。
